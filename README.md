# 🏎️ Car Show 2027 Registration System

A full-stack web application built to modernize and streamline car show participant registrations, payment tracking, 
and real-time event analytics. This system replaces legacy manual paper forms with an intuitive React dashboard connected 
to a C# ASP.NET Core Vertical Slice backend API.
